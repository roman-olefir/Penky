# Пеньки

Карткова гра для 2–6 гравців, у яку можна грати просто в браузері: з друзями або з ботами, на комп'ютері чи телефоні. Реєстрація не потрібна, достатньо придумати нікнейм.

## Про гру

Мета: позбутися всіх карт. Хто останнім залишиться з картами, той програв і стає «пеньком».

Гра йде колодою на 36 карт і має два етапи:

1. **Набір карт.** Гравці по черзі тягнуть карти з колоди й кладуть їх на купки суперників або собі. Масть останньої карти стає козирем, але піка козирем не буває.
2. **Гра.** Кожен бере свою купку в руку. Гравці по черзі б'ють верхню карту на столі, а хто не може або не хоче бити, бере нижню карту зі столу.

Підказок немає: за правилами кожен стежить сам. Хто порушує їх, робить **провтик** і отримує від інших гравців карти «по поганій».

Повні правила є в самій грі, за кнопкою «Правила».

## Можливості

- Кімнати за кодом із 4 цифр, публічні й приватні
- Боти трьох рівнів: легкий, середній і складний
- Інтерфейс для телефона й комп'ютера
- Повернення до гри після обриву зв'язку

Бази даних немає: кімнати зберігаються в пам'яті сервера й зникають після його перезапуску.

## Запуск

Потрібен [.NET 8](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet run --project CardGame --no-launch-profile --urls http://0.0.0.0:5033
```

Гра відкриється за адресою `http://localhost:5033`. З телефона в тій самій мережі заходьте за адресою `http://<IP комп'ютера>:5033`.

Запуск тестів:

```bash
dotnet test
```

## Технології

ASP.NET Core і SignalR на сервері, звичайні HTML, CSS і JavaScript у браузері.
